## Cross-cutting invariants and open decisions

- **Ownership:** retain the legacy single simulation owner/UI separation concept, not its large `Game`/`Commander` by-value graph or runtime-copy patterns. Rust state, shared immutable asset storage, command application and render snapshots should have explicit bounded ownership. Physics/docking/source receipts determine truth; rendering cannot create gameplay authority.
- **Time and determinism:** legacy `Game.tick` rejects nonfinite/nonpositive delta and clamps accepted delta to0.1seconds ([Game.swift:6615](/Volumes/SSD/offload/l337-g1-pr335-equipment-compose.UtqLRJ/required-cold-runtime.a11fe169/elite/Sources/L337Core/Game.swift:6615)); presentation has separate cadence. Define Meridian's step policy explicitly and prove equivalent mechanics for chosen reference traces. Exact IDs/integer accounting versus tolerant floating-point geometry need separate comparison rules. Do not inherit arbitrary outdated route/hull literals.
- **Transactions:** decide one current Rust save model and failure-atomic publication boundary before mission logic spreads. Persist identity and attained state, reconstruct ephemeral confirmation/arrival authority after load; do not serialize a reusable permission token. The selected legacy writer/receiver/refusal tests are useful adversarial specifications.
- **Renderer:** wgpu is fixed by the human; winit remains proposed. Shader interfaces, asset conversion, texture format/orientation, screen coordinates, color/depth handling, text rendering and GPU fallback behavior are not yet designed or tested here. The plan specifies observable behavior, not unverified API recipes or dependency versions.
- **First mission fidelity:** read the full G02Lua callbacks and freight/collection/clue transaction path during implementation. This report traced the manifest, finite source allocation, actual receiver and seven/eighth settlement/Continue tests; it is not an exhaustive formal model of every callback. The separate current M01/cold548 app result remains Root/G1 evidence, not a result of this plan.
- **Assets/rights:** current original assets and provenance can be candidates for reuse. Confirm notices/licenses for each copied pack, image, texture, Lua dependency and tool. Screenshots and marketing media do not substitute for native geometry/material source. No legal clearance or third-party compatibility is claimed.
- **Unknown completion and estimates:** remaining physical fleet qualification, all64mission runtime outcomes and current unresolved legacy faults prevent a reliable whole-port date. Sequence and acceptance boundaries are concrete; calendar estimates require Root's selected architecture, actual author/executor capacity and a measuredM1prototype.

The immediate implementation handoff isM0 plusM1's small vertical slice: freeze currentSH025/Avenor/Renas/G02source and units; choose Rust state/command/save/snapshot boundaries; make the wgpu desktop loop; then prove flight/dock/trade/custody and a real cold Continue. Full64mission/171catalogue parity remains explicit later work.
