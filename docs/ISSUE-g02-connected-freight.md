# Connect original G02 freight rules to one owning World

The isolated `freight::SupplyBatch` can transfer unit IDs but does not establish consent, current named contacts, actual Avenor/Renas arrival, an owned fit, wallet settlement or trusted clue custody. Treating its completion value as authority would allow a disconnected demonstration to appear complete.

Implement a bounded source-grounded mission state machine and prepare/commit account transaction, with public command data and a crate-private World boundary. Preserve sixteen source units, disjoint eight-unit jobs, confirmed review, exact original receiving order, once-per-job 730 CR, first-source clue and atomic refusals. Keep physical navigation, equipment and save authority in World.

Acceptance requires the owning World join, real journey and save-failure checks as well as domain tests. Current source/test limitations and immutable provenance are in [G02-CONNECTED.md](G02-CONNECTED.md).
