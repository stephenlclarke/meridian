A new process must continue the same owned commander, actual dock or flight, cargo, fit, fuel, market stock, freight transfers and once-only reward. Invalid files must not reset or repair the player. An in-memory codec or a byte-store test alone does not satisfy this.

Join the exact core codec, host file custody and actual title/save/quit controls. Test partial and completed journeys across separate processes through those same lifecycle methods, then qualify the native app without inferring GPU or held-key behavior from headless tests.
