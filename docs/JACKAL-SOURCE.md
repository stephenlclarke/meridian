# Jackal source envelope

The SH051 Jackal package preserves the original violet-pearl detailed and native artwork in relative coordinates. The frozen engineering calibration is 10,000 / 959 metres per source unit, or approximately 10.427528676 metres per unit. It gives calibrated detailed bounds of 24.421 m wide, 7.947 m high, and 30 m long.

The frozen runtime catalogue disables player flight and normal purchase. The original R3 design contract specifies player flight after blueprint fabrication. This delivery covers catalogue inspection and geometry queries.
