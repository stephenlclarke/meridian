# Cavy Racer source evidence

SH101 preserves both original pearl-teal meshes at one metre per source
unit. The detailed mesh has 3,084 triangles and 27 closed components.
The native mesh has 160 triangles and eight closed components. The
finite empty-dry reference records 16,567 kg. The runtime catalogue
records flight as unavailable and purchase pending fabrication.
The R3 design contract specifies player flight and blueprint fabrication.

Both original meshes preserve the same eight measured structural
overlaps. These include the pressure spindle against the canopy, the
braces against the spindle and outriggers, and each outrigger against
its nozzle. The detailed mesh has 31 extra measured pairs, including
contacts involving the nozzle layers, canopy ridge, pipes, housings
and louvres preserved in that mesh.

The 23 local supports use 20 mm rounding. Seven guards provide
729–1,132 mm clearance, including 729 mm between the aft nozzles and
863 mm above each outrigger. The maximum measured vertex-to-surface
distance from native to detailed is 90 mm. A detailed vertex is more
than 1,660 mm from the native surface.

Both Developer ID–signed offline Studio runs used the two original
meshes, passed all seven probes, and produced byte-identical exports.
