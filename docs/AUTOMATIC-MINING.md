# Automatic asteroid mining and physical ore intake

This extends the existing Avenor belt and owned front Mining Laser. It does not introduce a second laser mount. SH025 has no dedicated mining utility in the immutable source. Automatic work records the exchange between actual owned front-compatible equipment. Selecting a different role or releasing automatic work returns the same previous combat laser. Manual paid fitting at a berth remains available. The explicit maximum equipment action owns a stored Mining Laser if no example is already owned; it does not displace the Naval front or charge the wallet. The pilot must have actual fitted scoops.

The Mining Laser uses its original physical first-contact query, damage, range, cadence, opening heat and shared energy pool. Only the selected actual asteroid can receive an automatic mining pulse. Manual override, missing tools, blocked contact, protected activity and insufficient hold capacity prevent automatic work. Finite yield appears after terminal depletion, never as cash or immediate cargo. The selected source remains relevant while its released fragments remain uncollected.

Stephen approved newly authored Meridian ore geometry. Each individual released unit has an asymmetric six-vertex mineral shard, with the existing outward eight-triangle topology. The shard's source identity, commodity, initial position and velocity come from the retained terminal mining stroke and finite yield grid. The common physical snapshot supplies the renderer and scoop geometry. This is a deliberate new authored mesh, not an imported or authenticated original cargo hull.

Manual intake requires the real currently fitted scoops, a live same-system finite fragment, a lower-forward ship-local centre strictly within 85 units, and compatible native hold capacity. Automatic intake also requires relative velocity no greater than 15 physical units per second and every shard vertex below, ahead and inside the same distance boundary. The approach is towards the lower-forward aperture, not the ship centre. Gold, platinum and gems use their native non-tonne quantity units. Protected mission custody is not collected.

Collection adds one native commodity unit and one account revision. It does not purchase market stock or change cash. The optional `MINT0001` save extension retains actual scoop item, source fragment, owner/visit, physical and publication clocks, player pose, speed and intake mode. Duplicate or expired source fragment receipts refuse. The station ownership replay admits sales from previously collected real cargo without fabricating a station purchase, and account/hold history include the independent producer. Old v17 saves without the extension retain their original encoding and cannot supply a collected receipt.

The source tests cover the actual paid public journey, stale and distant collection refusal, cold once-only intake and sale, explicit maximum-owned front exchange, full native tonne hold and zero-tonne commodity fit, selection release, preserved resources and irregular moving-shard geometry. Platform execution and the combined protected-source witness remain separate qualification evidence.
