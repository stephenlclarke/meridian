# Wombat source evidence

Wombat preserves its 3,544-triangle detailed mesh and 1,024-triangle original
native mesh. The pinned creator independently reproduced both in full. Angular
reduction alone would still require at least 520 triangles if all fixed
components and loft stations were retained. The 512-triangle inspection budget
therefore uses a separate, project-authored 496-triangle native appearance.

The frozen relative source uses the exact calibration of 23,000/1,211 metres per
unit and retains the 167,216 kg finite empty-dry source. The candidate keeps 20
original parts byte for byte, including all frame members and eight blind wells.
It resamples eight curved parts at every original longitudinal station using
their original cardinal points. All six archived native axis extrema match.
Both archived meshes retain the four inboard pod wells that the candidate
omits. They are original native part indices 12, 15, 18 and 19, with a certified
mouth-to-floor upper bound of 988 mm at each original corner.
