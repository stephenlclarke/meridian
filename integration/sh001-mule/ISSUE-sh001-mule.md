# SH001 Mule: first original-hull delivery

## Motivation

The current backlog identifies Mule as the first unimplemented ship. Its selected visual and engineering data exist, but its 1,772-face exact native source is unqualified at the existing 512-face contract. The human authorized a separate smooth, tight, conservative gameplay envelope with a very slight close-up shield shimmer.

## Implementation and acceptance

Bind all original fields, components and engineering data. Use sixteen rounded convex source supports with a 2 cm offset for gameplay contact and docking, preserving pannier gaps. Keep the exact geometry contract/history separate. Add complete source containment, continuous contact, strict port fit, ray uncertainty and shield presentation tests. Hand the same immutable surface to the existing renderer owner.

This is a source/core prototype, not completed hull admission. World actor identity/generation, actual paid acquisition/crew/fitting/save/contact/EMP wiring, renderer evidence, ordinary gameplay, qualification and Root protected main integration remain required. Work stays on Mule until actual acceptance. See [the design and current status](../../docs/MULE-GAMEPLAY-ENVELOPE.md) and [criteria](CRITERIA.json). No GitHub issue number is assigned.
