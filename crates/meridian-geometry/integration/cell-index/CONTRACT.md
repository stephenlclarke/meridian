## Compact exact source order

Canonical finite, joint and ray traversals emit at most one record per original ordinal because node leaves partition the permutation. Candidate flags and full payloads must return in ascending original order. Legacy and contiguous indexes retain their original source-order body and exact charges. Only the new mode uses compact rank restoration.

Build a fresh bit set over [0,N) for this one candidate vector. Range checks and duplicate checks precede every bit insertion. A prefix population count per 64-bit word gives rank(key) = prefix[word] + popcount(wordBits below key). Unique valid keys imply ranks exactly [0,K), so the target is always an existing output position. Cycle swaps move each complete record to that target in place. Each swap places at least one record; the process terminates after at most K-1 swaps. It preserves ordinal, physical/outward flags and every copied payload field. No geometry or parity bit is recomputed or merged. Invalid range or duplicate metadata returns a typed InvalidWitness. Empty and single-record cases need no ordering allocation; the single key still receives its range check.

Bits and rank prefixes are initialized anew per query and drop on return. They are candidate-set metadata, not sampled occupancy, intersections or cached ray answers. Existing generic-ray generations and policies are unchanged. There is no new across-query or across-ray result cache.
